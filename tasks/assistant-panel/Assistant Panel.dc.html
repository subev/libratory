2What the assistant can do: MCP tools as cards

One tool set. The assistant calls the same tools as mcp-server.ts, with nothing built just for the panel. The rule is set per tool:

  • Read-only (list_books, get_book, inspect_pdf, search_library…) runs without asking and shows as a one-line trace.
  • Small, easy to reverse (rename, move to a folder, save a note) runs straight away and shows Undo.
  • Changes something shows a card and waits for Run.
  • Spends credit or downloads shows the same card with a cost line.

Staged files. A dropped PDF is uploaded to data/tmp and gets an ID like staged:ab12. inspect_pdf and upload_book accept these IDs alongside paths, so the model never sees the file system. From the panel, upload_book runs with fullExtract=false: a text-only book in seconds, and the assistant suggests the next step.

1Assistant panel — first pass

Idea. The assistant is docked on the right and open on first launch. Until a model is connected, the panel has one job: pick a provider, follow three steps, paste the key. Once connected, it explains the extract → synthesize → output loop, knows the current page and book, suggests the next step and runs it after you confirm.

Also a drop zone. Once a model is connected, drop PDFs on the panel or use the paperclip. The assistant reads them and suggests how to add them: one book each, combined into one, or edit titles first. You don't have to go to the Library page.

Free path. “On this Mac” is one of the provider tiles, so someone with no cloud account can unlock the assistant with Ollama or LM Studio.
