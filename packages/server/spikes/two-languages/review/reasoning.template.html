Broad counterpart warnings are a separate, post-hoc check: one reasoning run grouped “small boy” and “small girl” as whole phrases, making each adjective also highlight the translated noun. Whole-phrase meaning is correct, but word-level highlighting is too broad.

These fixtures and checks are agent-authored, not native-reviewed. Better text mapping does not improve the stored audio timings: Hebrew has uniformly spaced intervals, while Bulgarian and German contain zero-duration words.
